Notes on ember

  • It sits next to the Institute's red. The Institute's red is #AC2A00 and ember is #CC5500, one step brighter in the same family, so the School reads as related.
  • Use it large. Ember is 4.3:1 on white and 3.8:1 on vellum, which suits large type, icons and color fields. Small text stays navy.
  • For Cypher. Ember can look like an ordinary error red to some viewers with color blindness. Error states should carry an icon and a word, not color alone.
